## 1. API Workflow Overview

Weekdays at 10:00 EET, queries Coupa for invoices dated in the past seven days with status draft or new. Excludes credit notes, checks each for a properly linked PO (PO in description only does not count), and counts qualifying invoices. If count > 0, sends one Slack DM to Irina Capatina (member ID WLX9BD8FN) with count, policy reminder, action request, and filtered Coupa link. If count = 0, sends nothing. AP SME acts on the notification to link missing POs.

**Trigger:** Orchestrator scheduler, weekdays 10:00 Romania time (EET/EEST).  
**Outcome:** Slack message sent (if count > 0) or clean completion. Log result to job execution history.

## 6. Error Handling

| Failure | Detection | Response | Notes |
|---|---|---|---|
| Coupa timeout / no response / 401 / 403 / malformed JSON | HTTP call or parse fails | Unhandled exception; run marked failed; no Slack sent | BR-08: no retry; PDD §9 S1–S3 |
| Slack HTTP error / response.ok ≠ true | HTTP status or validation fails | Javascript_ValidateSlack throws; unhandled exception; run failed; no notification | BR-08, BR-09: no retry; PDD §9 S4 |
| Credential missing | Orchestrator lookup returns null | HTTP Request fails; unhandled exception; run failed | Deployment prerequisite: credentials must exist |
| Unhandled exception | Any uncaught error in any activity | Single edge handler logs stack trace; marks run failed | BR-08, BR-09: no notification on any failure |

**Summary:** No retry, no fallback, one outcome. Happy path or failure. Count = 0 is successful completion, not a failure (BR-07).

## 8. Testing Strategy

### Happy Path: Qualifying Invoices Found

| Assertion | Method |
|---|---|
| Coupa list includes draft/new invoices within window | Mock HTTP: 2+ invoices, correct statuses and dates |
| Credit notes excluded | JS unit test: `invoice-type == 'Credit Note'` removed |
| PO linkage detection | JS unit test: invoices with `po-number` or `order-header-num` excluded; others included |
| qualifyingCount > 0 triggers Then branch | Workflow execution |
| Slack payload valid Block Kit | JSON validation: channel, text, blocks (header, section, button, context) |
| Slack message sent | HTTP 200, response.ok = true |
| Output correct | status = "Successful", qualifying_count > 0, slack_sent = true |
| Job logs written | Console: `qualifying_count=N`, `slack_sent=true` |

### Business Exception: Clean Day

| Assertion | Method |
|---|---|
| qualifyingCount = 0 after filters | All invoices have POs or are credit notes |
| Else branch taken | No Slack composition |
| No Slack sent | HTTP_Request_Slack not executed |
| Run successful | status = Completed, not Failed |
| Output correct | status = "Successful", qualifying_count = 0, slack_sent = false |

### System Errors: Coupa Failure, Slack Failure, Credential Missing

| Scenario | Expected |
|---|---|
| Coupa HTTP 401/500 | Run failed; no Slack |
| Slack HTTP 400/429 | Run failed after validation throws |
| Missing credential | HTTP activity fails; run failed |
